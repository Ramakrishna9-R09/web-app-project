# VIT Connect

VIT Connect is a student community web app for VIT students to connect through communities, posts, profiles, and shared campus discussions.

## Live Demo

[https://vit-connect-app.vercel.app](https://vit-connect-app.vercel.app)

## Repository

[https://github.com/Ramakrishna9-R09/vit-connect](https://github.com/Ramakrishna9-R09/vit-connect)

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Firebase
- Zustand

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
